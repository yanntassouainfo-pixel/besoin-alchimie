# Besoin d'Alchimie — prototype de plateforme

Prototype navigable : une bibliothèque privée d'expériences à vivre à deux.
Site statique, sans serveur ni base de données. Tout ce qu'un couple écrit
reste dans le navigateur de l'appareil (localStorage).

**Tout le contenu est fictif.** Ce dépôt sert à montrer et à tester le parcours.

- Mise en ligne : GitHub Pages, branche `main`, racine du dépôt.
- En local : `node .serve.js` puis http://localhost:4181
- Détail du contenu et des mécaniques : [A-LIRE.md](A-LIRE.md)

La page porte `<meta name="robots" content="noindex, nofollow">` : elle ne doit
pas être indexée par les moteurs de recherche.
